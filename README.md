# Road Runner

A browser endless-runner: dodge road obstacles in a BMW 550i or a Nissan Cube.

Live app: (https://roadrunner-dvas.vercel.app/)

## Features

- **Opening cutscene**: a movie-trailer style intro that plays real demo gameplay with letterboxing, captions, zoom shots, slow motion and flash cuts. Skip it with any key or tap, or turn it off in Settings.
- **Garage**: pick a car, then customize body paint, window tint, rim color (presets or a custom color picker) and wheel style (Stock, Sport, Turbo, Mesh, Chrome, Classic).
- **Map**: five road worlds (City Day, Sunset Boulevard, Neon Night, Desert Run, Snow Pass).
- **Settings**: difficulty, sound effects, screen shake, intro on/off, theme (system/light/dark), replay intro, reset best score, reset garage and map.

Your best score, car colors, wheels, map and settings are saved in the browser (localStorage).

## Controls

- Space / ↑ / tap: jump
- P or Esc: pause (Esc on a menu goes back)
- 1 / 2: switch cars from the main menu

## Running

Open `index.html` locally or deploy as a static site. No build step.
